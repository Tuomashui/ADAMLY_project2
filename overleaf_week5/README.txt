WEEK 5 - EDITABLE OVERLEAF PROJECT

Upload overleaf_week5.zip using New Project > Upload Project in Overleaf.
Set the main document to main.tex and the compiler to pdfLaTeX.

Edit main.tex for the title, authors, methods, and references.
Edit sections/results.tex for measured results, tables, captions, discussion,
and conclusions. These are ordinary editable LaTeX files.
Figures are stored in figures/imdb and figures/banking77.
The complete 77-class frequency plot is figures/banking77/class_counts.pdf.
The data folder contains summary metrics, dataset metadata, example texts,
length statistics, and the recorded configuration and environment.

The project compiles independently of Python and the original repository.
To compile locally, run pdflatex main.tex twice from this folder.
The title-page date uses the compilation date through the LaTeX today command.
